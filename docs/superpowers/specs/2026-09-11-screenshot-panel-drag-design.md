# SpotBrief 截图与面板拖动设计

## 目标

为 SpotBrief 增加两个独立但协调的能力：用户主动授权后在当前可见网页中拖出矩形截图；用户通过拖动顶栏移动工作面板，并在下次启动时恢复位置。

## 截图交互

1. 工作面板提供“截取页面区域”入口。
2. 用户点击后调用 Screen Capture API，由浏览器要求用户选择共享内容。
3. 用户授权后进入矩形选择模式；SpotBrief 面板和现有 Overlay 暂时隐藏。
4. 页面显示固定定位的遮罩、操作提示和拖拽矩形，截图模式中暂停页面滚动及业务点击。
5. 用户按住主鼠标键并拖动，只能选择当前视口内的矩形区域。
6. 松开鼠标后按共享视频帧与当前视口的比例裁切 PNG。
7. 宽度或高度小于 20 CSS 像素的区域视为无效，恢复界面并提示重新截图。
8. `Esc`、授权取消或流结束均取消本次截图，恢复面板和 Overlay，不影响现有草稿。
9. 成功后停止全部媒体轨道，恢复工作台并显示截图预览、像素尺寸和文件名。
10. 截图操作提供“复制 PNG”“下载 PNG”“重新截图”和“删除截图”。
11. Clipboard PNG 不受支持或写入失败时显示错误，并保留下载 PNG 入口。
12. 截图只保存在当前运行时内存；关闭工具时撤销对象 URL、停止媒体轨道并删除截图状态。

## 任务书集成

成功截图后，`BriefDraft.screenshot` 保存文件名和“用户手动选择的页面区域”说明。生成 Markdown 时仅在截图存在时输出截图章节；JSON 同步包含元数据，不嵌入 Base64 图片内容。

## 面板拖动交互

1. 用户按住顶栏的非按钮区域拖动面板。
2. 从按钮、输入控件或链接开始的指针操作不触发拖动。
3. 使用 Pointer Events 和 pointer capture 保证拖动连续。
4. 面板位置以视口左上角为基准保存为 `{x, y}`。
5. 拖动过程中将坐标限制在视口内，至少完整保留顶栏及关闭按钮；正常情况下尽量保持整个面板可见。
6. 拖动结束时保存位置到 `patchbrief:preferences`，不保存页面内容、选区、代码或截图。
7. 再次启动时读取位置并恢复；数据无效、localStorage 不可用或位置超出当前视口时回退或收敛到可见范围。
8. 窗口 resize 后重新收敛位置。
9. 面板提供“恢复默认位置”，删除保存坐标并回到右上角。
10. 视口宽度不超过 620px 时继续使用底部抽屉布局，禁用自由拖动与坐标恢复。

## 状态与冲突处理

- 截图选区期间禁用面板拖动，因为面板已隐藏。
- 截图期间暂停元素检查和业务页面点击；结束后恢复原先的暂停状态。
- 重复点击截图入口时不创建第二个媒体流或第二层遮罩。
- 工具关闭时必须移除截图遮罩、拖动监听器、对象 URL、媒体轨道和临时页面样式。
- 面板重新渲染时保留当前截图和位置状态。

## 测试

### 单元测试

- 矩形标准化：支持从任意方向拖动。
- 小矩形判定。
- 视频像素与视口 CSS 像素的裁切换算。
- 面板坐标在不同视口和面板尺寸下的边界收敛。
- 偏好设置中位置的保存、读取和无效值降级。
- 有截图和无截图时任务书章节的输出与省略。

### 浏览器测试

- 拖动顶栏后面板位置发生变化。
- 从顶栏按钮开始操作不会拖动面板。
- 刷新或重新注入后恢复保存位置。
- 恢复默认位置可用。
- 截图模式显示矩形选择层，拖拽后出现预览。
- `Esc` 取消后完整恢复面板和页面滚动。
- 复制失败时仍能下载。
- 关闭工具后截图层和拖动状态完整清理。

## 边界

- 不实现整页长截图，只截取当前视口可见区域。
- 不绕过浏览器授权，不声称静默截图。
- 不把 PNG 内容写入任务书、localStorage 或远端服务。
- 不在本次实现草稿历史、多份截图、图片标注、OCR、父子/兄弟键盘导航。
