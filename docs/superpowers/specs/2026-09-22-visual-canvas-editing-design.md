# SpotBrief 视觉画布编辑设计

## 背景与目标

SpotBrief 当前支持在网页上点选元素、填写修改要求，再生成结构化任务书。本次增加轻量视觉画布能力：用户可在原页面上直接拖拽、吸附、缩放、调整圆角和颜色，SpotBrief 记录每个元件的前后差异，与文字说明一起生成任务书。

本功能仍是“修改意图工作台”，不是持久化网页编辑器。所有 DOM 变更都是当前会话的临时预览；关闭 SpotBrief 时必须完整恢复页面初始状态。

CanvasCode 的拖拽和吸附交互用作产品参考。该项目使用 GPL-3.0；SpotBrief 仅借鉴交互概念，全部代码独立实现，不复制参考项目的源码。

## 用户体验

### 启动与选中

- SpotBrief 启动后继续支持悬停高亮和单击选中。
- 选中元件后默认打开单行编辑器，用户可随时关闭；再次选中时重新打开。
- `Shift` + 单击增加或移除多选元件。
- ↑ 切换到父元素，↓ 返回原路径上的子元素。输入框、文本区和可编辑内容获得焦点时不劫持方向键。
- 多选时单行编辑器仅呈现所有选中项都适用的属性；属性值不一致时显示“多值”状态。

### 单行编辑器

常态编辑器只占一行，不显示“编辑元件”标题，包含：

1. 圆角滑杆与当前数值。
2. 当前填充颜色按钮。
3. “说明”按钮。
4. “重置”按钮。
5. 关闭编辑器按钮。

点击颜色才展开紧凑调色板；点击“说明”才展开文本输入浮层。面板不显示位置坐标或宽高输入。

单选时“重置”恢复该元件的位置、尺寸、圆角、颜色和修改说明。多选时“重置”恢复当前选中的全部元件。重置作为一个可撤销的复合动作。

### 拖拽、吸附与尺寸

- 用户拖动选框边缘移动单个元件或整个多选组。
- 拖拽使用 Pointer Events、pointer capture、`requestAnimationFrame` 和 `translate3d`，避免丢失指针和频繁布局抖动。
- 拖拽开始时一次性采集同级元素和可见主要容器的边界；拖拽帧内不重复扫描整个 DOM。
- 默认对齐左、水平中心、右、顶、垂直中心和底部；阈值使用一个可配置常量。
- 吸附发生时显示对齐参考线和简短说明；未吸附时不显示位置数值。
- 按住 `Alt` 临时关闭吸附，进行自由拖拽。
- 选框提供八个尺寸手柄。边中点改变单轴尺寸，角点改变宽高；`Shift` + 拖动角点保持纵横比。
- 多选拖拽保持元件间的相对位置。多选尺寸调整不进入首版，避免不可预期的批量缩放。
- 键盘方向键已用于父子级切换，因此不用于像素微调。精确尺寸可通过拖动手柄完成；任务书会记录最终像素差异。

### 修改位置编号

- 元件第一次产生实际视觉变更或非空修改说明时，获得一个从 1 开始的位置编号。
- 同一元件的多次拖拽、缩放和属性编辑始终共用一个编号。
- 编号标记固定在元件选框附近，并随滚动、拖拽和尺寸变化更新位置。
- 点击编号会将元件滚动到可见区域并重新选中。
- 当元件完全重置、修改说明也为空时，其编号被移除；剩余元件立即按初次变更顺序连续重排。
- 底部任务条同时显示“N 处 · M 项变更”。N 是已修改元件数，M 是输出到任务书的属性差异与说明数。

### 底部任务条

原大型任务面板改为居中的紧凑半透明深色浮动条，包含：

- 修改位置数和变更项数。
- 撤销和重做。
- “任务设置”入口。
- “生成任务书”主操作。

“任务设置”展开现有全局修改目标、相关代码、修改约束、截图和 AI 优化选项；关闭后回到单行任务条。

## 变更数据模型

每个受影响元素保留一份会话内记录：

- 稳定的会话 ID、可读选择器和可访问名称。
- 第一次编辑前的原始 inline style 字符串以及所有需恢复属性的原始值。
- 初始边界与当前边界。
- 位移、宽高、圆角、填充颜色的初始值和当前值。
- 元件修改说明。
- 首次产生变更的顺序，用于连续编号。

多选批量说明作为选中元素集合的共享说明记录，任务书输出时同时挂载到这些元件的组合变更项上，不简单复制为多份文本。

## 历史、重置与恢复

- 所有操作共用一个命令历史：单选/多选位移、尺寸调整、圆角、颜色、单元件说明、批量说明和重置。
- 拖拽、滑杆和连续输入在交互进行期间只实时预览；指针松开、键盘确认或输入失焦时压缩成一条历史命令。
- 新操作发生后清空重做栈。历史保留一个有限上限，避免长时会话无限增长。
- 关闭或销毁 SpotBrief 时，先按记录恢复每个元素的原始 inline style，再移除 Overlay、编辑器、任务条和事件监听器。
- 页面自身在会话中删除或替换元素时，记录标记为失效，不对新元素强行应用旧样式。

## 任务书输出

任务书按当前连续编号输出“修改位置 1、2、3…”。每处包含：

- 可访问名称、标签、选择器、页面区域和必要的脱敏 HTML 摘要。
- 用户的单元件说明或关联的批量说明。
- 位移差异（`dx` / `dy`）及最终吸附关系。
- 尺寸前后值。
- 圆角前后值。
- 填充颜色前后值。
- 经过重置、值已回到初始状态的属性不输出。

Markdown 使用适合人和 AI 阅读的前后对比；JSON 使用明确的 `before` / `after` / `delta` 字段。不将临时 DOM 、历史栈或截图 Base64 嵌入输出。

## 响应式、可访问性与安全

- 桌面端使用右上角单行编辑器和底部居中任务条。屏幕宽度不足时，编辑器和任务条改为不超出视口的底部堆叠布局。
- 拖拽和缩放不是唯一输入途径：选框手柄可通过键盘获得焦点，并使用方向键调整手柄对应边界；该行为仅在手柄聚焦时生效，不与父子级快捷键冲突。
- 图标按钮提供可访问名称和焦点样式。紧凑界面不通过缩小点击区实现；视觉图标可小，交互热区保持可操作。
- 尊重 `prefers-reduced-motion`；不依赖长动画传达状态。
- 工具 UI 保持在 Shadow DOM 中，所有覆盖层标记 `data-patchbrief-ui`，避免被当成网页目标。
- 不读取或修改跨域 iframe 内容，不尝试绕过浏览器安全限制。

## 错误与边界处理

- 不适合直接变换的元素（如 `html`、`body`、工具 UI）不显示编辑手柄。
- 元素原本已有 `transform` 时，位移预览不覆盖原变换；使用受控的变换组合或包装策略，任务书仍记录位移差异。
- 元素使用流式布局、Flex 或 Grid 时，拖拽只做视觉位移，不在首版自动改写 DOM 顺序、Flex 参数或 Grid 区域。
- 尺寸下限防止元素缩小为不可操作状态。不对具有固有尺寸的替换元素作不安全改写。
- 颜色解析失败时保留浏览器原始字符串，不伪造色值。
- 当页面 MutationObserver 发现已编辑元素失联时，序号显示失效状态；用户可重置记录或保留其文字说明生成任务书。

## 测试策略

### 单元测试

- 位移、尺寸和圆角数值的计算与边界限制。
- 单选与多选拖拽后的相对位置。
- 吸附候选的边、中心和阈值匹配。
- 属性前后差异计算，回到初始值后移除差异。
- 命令历史的撤销、重做、连续操作压缩和新操作清空重做栈。
- 单元件和多元件重置的恢复与可撤销性。
- 位置编号的分配、去重、删除和连续重排。
- Markdown 和 JSON 的前后差异输出。

### 浏览器测试

- 选中元件后打开单行编辑器，关闭后不丢失选择和变更。
- 单选拖拽、吸附线、`Alt` 自由拖拽和八手柄尺寸调整。
- `Shift` 多选、整组拖拽、共同属性和批量说明。
- 圆角、颜色和说明的紧凑编辑交互。
- 序号显示、点击定位、重置后连续重排。
- 底部任务条的计数、撤销、重做、任务设置和任务书生成。
- 关闭 SpotBrief 后页面属性、inline style、光标、Overlay 和事件监听器全部恢复。
- 屏幕缩小后单行编辑器和底部任务条不超出视口。

## 首版边界

首版不实现：

- 改写 DOM 元素顺序、Flex/Grid 结构或自动重排源码。
- 文字原位编辑、字体、字号、边框、阴影、内外边距和 z-index 调整。
- 多选组的整体比例缩放。
- 将临时编辑结果直接写入本地源码或远程代码库。
- 刷新页面后恢复上一次的视觉编辑会话。

## 验收标准

1. 用户可在同一会话中修改多个元件，并清楚看到每个修改位置的连续编号。
2. 单选支持拖拽、吸附、尺寸调整、圆角、填充颜色和修改说明。
3. 多选支持整组拖拽、共同属性编辑和批量说明。
4. 全部操作可通过同一套撤销/重做恢复，单元件或多选重置也可撤销。
5. 任务书同时包含元件定位、用户说明和可执行的前后差异。
6. 关闭 SpotBrief 后页面回到启动前的状态，不遗留临时样式或监听器。
