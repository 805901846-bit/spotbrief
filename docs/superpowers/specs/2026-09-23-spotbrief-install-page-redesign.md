# SpotBrief 安装页重构设计

## 目标

将安装页从常规工具介绍页重构为有明确产品感的展示页。首要任务仍是让用户快速安装 Bookmarklet，同时在不过度增加阅读成本的前提下，说清如何使用、具体操作和最终效果。

## 设计读取

- 页面类型：开发者工具产品落地页。
- 目标用户：产品经理、设计师和使用 AI 编码工具的前端协作者。
- 视觉语言：Ascera 式全幅深色山景，冷白产品界面悬浮其上，单一青绿色用于操作和选中状态。
- 设计参数：Design Variance 7，Motion 3，Visual Density 5。
- 主题：页面整体保持同一个深色场景与冷白表面体系，不在中途切换成无关的色系。

## 信息架构

### 首屏

- 全幅深色山景作为环境背景，叠加可读性遮罩。
- 顶部为半透明悬浮导航，包含 SpotBrief 品牌、页内锦标链接、语言切换和次级安装入口。
- 中央仅保留主标题、一段简短说明和主安装按钮。
- 安装按钮保持真实 Bookmarklet 拖拽能力，辅助文案说明如何显示书签栏。
- 首屏底部展示紧凑的真实 SpotBrief 操作状态：选中框、编号、单行编辑器和任务条。

### 如何使用

使用紧凑的两列流程，不使用三张等宽卡片。流程按真实产品操作组织：

1. 选中：点击页面元件并打开轻量编辑器。
2. 调整：设置圆角、颜色和修改说明。
3. 拖拽：移动或拉伸元件，靠近参考边时吸附，Alt 临时禁用吸附。
4. 多选：Shift + 点击进行多选，支持整组移动和批量说明。
5. 检查：通过连续编号定位变更，执行撤销、重做或单项重置。
6. 生成：将视觉变更和修改说明合并成结构化任务书。

### 使用效果

- 展示真实操作后的选中框、变更编号和紧凑工具条。
- 使用静态前后对比，不引入需要学习的交互演示。
- 同时展示任务书中的差异输出，包括 Selector、修改前后属性和单项说明。
- 展示内容必须来自当前已实现能力，不添加未实现功能或伪造指标。

### 信任与配置

- 简短说明本地处理、关闭后恢复原页面和浏览器支持范围。
- AI 优化保留为可选高级配置，放在主流程之后，不干扰安装。
- API Base URL、模型和 API Key 字段名及存储行为保持不变。

## 视觉系统

- 色彩：山景的石灰与深绿作为环境色，界面表面使用冷白与浅灰，交互强调统一使用青绿。
- 字体：使用现有系统字体栈，不增加网络字体依赖。标题靠字重、紧密字距和尺寸建立层级。
- 形状：导航、操作面板和内容容器采用 10-16px 的统一软圆角，按钮不使用过度胶囊化。
- 材质：半透明表面使用弱模糊、内边框和着色阴影，不使用外发光。
- 图标：优先使用文字标签或项目已有图标，不新增 emoji 和手绘 SVG 图标。

## 动效

- 首屏只使用轻微透明度和位移入场，用来表达信息层级。
- 按钮保留明确的 hover、active 和 focus-visible 状态。
- 不使用滚动劫持、无限循环、粒子或无功能意义的光效。
- 所有动效遵守 `prefers-reduced-motion`，降级后内容保持完整可读。

## 响应式与可访问性

- 桌面首屏在常见视口内展示完整标题、主安装按钮和产品预览。
- 移动端改为单列，隐藏非核心导航项，产品预览宽度不超过视口。
- 可点击控件最小触摸区域为 44px，所有交互控件保留可见焦点。
- 主文本对比度达到 WCAG AA，背景图上的文本通过遮罩保证可读性。
- Bookmarklet 链接保留真实拖拽行为，同时提供简洁的键盘和安装说明。

## 错误与状态

- Bookmarklet 负载中、就绪和失败状态必须可见，失败时保留刷新重试提示。
- AI 设置表单保留可见 label、原有验证和保存结果提示。
- 背景图加载失败时使用可读的深色渐变后备，不影响安装。

## 测试与验收

- 更新安装页端到端测试，覆盖安装按钮就绪、语言切换、AI 设置保存与页面主要内容。
- 验证 375px、768px、1024px 和 1440px 视口，不出现水平滚动。
- 验证键盘 Tab 顺序、focus-visible 状态和减少动效偏好。
- 构建后验证 `dist/index.html`、安装脚本和 Bookmarklet 负载仍然可用。
- 完成后使用 ui-ux-pro-max 执行规范检查，再用 Impeccable 完成一次桌面与移动端的终局审核。

## 范围边界

- 不修改 Bookmarklet 核心产品能力。
- 不改变 AI 配置的字段、存储键和配对流程。
- 不引入新前端框架或运行时依赖。
- 山景素材必须有明确可用授权，并作为本地资产随项目发布，不在页面中依赖远程图片。
