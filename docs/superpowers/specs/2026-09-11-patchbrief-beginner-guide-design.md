# SpotBrief 零基础本地使用说明书设计

## 目标

为没有计算机基础、使用 Google Chrome 的用户编写一份可以逐步照做的 SpotBrief 本地使用说明书。说明书只覆盖当前电脑上的本地安装页面，不介绍 GitHub 发布或其他浏览器。

## 读者假设

- 不理解终端、localhost、Bookmarklet、DOM 等技术术语。
- 可以进行鼠标点击、拖动、复制和粘贴。
- 需要明确知道每一步在哪里操作，以及看到什么表示成功。

## 写作方式

- 使用简体中文和短句。
- 每个编号步骤只安排一个主要动作。
- 必须使用技术词时，紧跟日常语言解释。
- 命令标记为“复制这一行，不需要理解”。
- 每个关键阶段附带“成功时你会看到”的提示。
- 不假设用户知道项目目录、终端窗口或书签栏在哪里。

## 内容结构

1. SpotBrief 是什么，以及它不会自动修改代码。
2. 使用前准备：Chrome、项目文件和本地页面服务。
3. 打开本地安装页面。
4. 显示 Chrome 书签栏。
5. 将 SpotBrief 按钮拖入书签栏。
6. 在普通网页或本地开发网页中启动工具。
7. 悬停、单击、Shift 多选和清空选择。
8. 用示例解释每个输入框该写什么。
9. 生成、预览、复制和下载任务书。
10. 将任务书粘贴给 Codex 等 AI 编码助手。
11. 暂停、最小化和关闭工具。
12. 常见问题：本地页面打不开、按钮未准备好、点击书签没反应、选错元素、复制失败。
13. 不支持页面和隐私提醒。

## 边界

- 不介绍 GitHub 上传和 GitHub Pages。
- 不介绍源码结构、构建原理或开发调试。
- 不声称支持 Chrome 内部页面、扩展商店或所有 iframe。
- 不声称可以读取本地源码、自动修改代码或静默截图。
- 对当前尚未接通的截图功能不提供使用步骤。

## 验收标准

- 零基础用户能独立完成打开页面、安装书签、选择元素、填写要求、生成任务书和粘贴给 AI。
- 每个关键步骤都有成功标志。
- 常见失败提供下一步处理方法。
- 操作说明与当前 SpotBrief 实际功能一致。
