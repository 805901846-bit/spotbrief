# SpotBrief 紧凑面板 v3 设计规格

## 目标

把书签工具面板收敛为“小而美”的单一路径：选择目标、填写修改要求、生成任务书。低频配置不占用主面板空间。

## 主面板

- 面板继续使用约 360px 的右侧浮层，但缩小顶栏、间距、按钮、卡片和输入框尺寸。
- 顶栏保留品牌、状态、设置、暂停、最小化和关闭；设置使用与关闭同行的小齿轮图标。
- 空选区提示改成一行：“点击页面元素开始选择”，其右侧仅保留一个紧凑的“截图”按钮。
- 每个选中元素显示紧凑卡片，保留名称、定位摘要、删除入口和“单独说明”输入框。
- 单独说明只用于该元素的特殊要求；为空时不输出对应字段。
- 主面板始终显示一个“修改要求”输入框，作为本次任务和全部选中目标的默认统一说明。
- 删除“全局修改目标”的名称、概念和下拉框。
- 删除“相关代码”字段、语言选择和代码字符统计。
- 底部只保留“清空”和“生成任务书”。删除可见的“撤销”按钮，但继续支持 `Ctrl/Cmd + Z`。

## 设置

点击顶栏齿轮进入紧凑设置视图，主面板低频内容移入这里：

- AI 优化任务书开关与 API 配置状态。
- 默认修改约束。
- 页面与输出设置，包括视觉摘要、局部 HTML 和语言等现有偏好。
- 返回主面板的入口。

如果安装页已经配置有效 API，新的任务草稿默认开启 AI 优化；用户可以在设置中关闭。未配置 API 时默认关闭，并提供前往安装页配置的明确提示。不得发送未清理的页面数据。

## 截图

- 主面板只有一个截图入口。
- 点击后继续沿用当前授权、选择标签页、拖拽矩形、裁切和内存保存流程。
- 截图成功后，在选择区域下方显示紧凑预览、截图说明和删除入口。
- PNG 复制与下载等次要操作放入截图预览的更多操作区域，避免常驻三个按钮。

## 任务书输出

- “修改要求”继续映射到 `BriefDraft.request` 和输出的“修改目标”章节，不改变任务书数据含义。
- 元素“单独说明”继续映射到每个 selection 的 `note`。
- 删除相关代码输入后，新生成的任务书不再由面板产生 `relatedCode`；生成器仍可兼容旧数据模型，避免无关破坏。
- 修改约束继续使用当前默认安全选项并进入任务书。

## 状态与兼容

- 保留历史内部标识、localStorage 键、书签运行时文件名和 `window.__PATCHBRIEF__`，避免已安装书签失效。
- 不迁移、不保存用户任务文本、选区或截图。
- 现有面板拖动、暂停、最小化、关闭和快捷键继续工作。
- 旧版本中保存的代码区展开状态可以被忽略，但不得导致初始化错误。

## 验收

- 默认面板中不出现“全局修改目标”“相关代码”“高级选项”“撤销”按钮或常驻 AI 开关。
- 截图按钮与选择提示同行，截图完整流程不回退。
- 两个元素可以分别填写单独说明；统一修改要求只填写一次。
- 设置页可以调整 AI、约束和输出偏好。
- 配置 API 时新草稿默认开启 AI；未配置时默认关闭。
- 生成、复制、下载、清空、键盘撤销、暂停、拖动和关闭均可用。
- TypeScript、单元测试、构建验证和 Playwright 端到端测试全部通过。
