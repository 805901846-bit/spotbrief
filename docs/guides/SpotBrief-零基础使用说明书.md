# SpotBrief 零基础使用说明书

> 适合：没有计算机基础、使用 Google Chrome、在当前这台电脑上体验 SpotBrief 的用户。

## 先用一句话认识 SpotBrief

SpotBrief 可以帮你在网页上指出“我想修改这里”，然后把你的要求整理成一份完整的文字任务书。

你可以把这份任务书交给 Codex、Cursor、Claude Code 等 AI 编码助手。

请注意：

- SpotBrief **不会自己修改网页或代码**。
- SpotBrief **不会读取你电脑里的项目源码**。
- 它的工作是帮你把修改要求说得更清楚。

---

## 第 1 步：打开 Google Chrome

1. 在电脑底部的程序栏里找到 Google Chrome。
2. 点击 Chrome 图标。
3. 等待浏览器窗口打开。

**成功时你会看到：** Chrome 的网页窗口，上方有一条可以输入网址的长框。

---

## 第 2 步：打开“终端”

“终端”是一个可以让电脑执行文字命令的窗口。你不需要理解里面的技术内容，只需要按照下面的步骤复制和粘贴。

1. 同时按下键盘上的 `Command` 和空格键。
2. 屏幕中间会出现搜索框。
3. 输入“终端”。
4. 点击搜索结果里的“终端”。

**成功时你会看到：** 一个白色或黑色的小窗口，里面有几行文字，最后一行等待你输入。

---

## 第 3 步：启动 SpotBrief 本地页面

### 3.1 进入 SpotBrief 文件夹

复制下面整行文字：

```text
cd "/Users/player1007/Documents/Codex/2026-09-03/7-30-teams-plugin-teams-openai"
```

回到终端窗口：

1. 点击终端窗口里面的空白位置。
2. 同时按下 `Command + V`，把刚才的文字粘贴进去。
3. 按一下回车键。

### 3.2 启动本地页面

复制下面整行文字，不需要理解：

```text
/Users/player1007/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node tests/serve.mjs
```

回到终端窗口：

1. 按 `Command + V` 粘贴。
2. 按一下回车键。
3. **不要关闭这个终端窗口。** 可以把它放到一边。

这条命令执行后可能没有任何文字出现。这通常不是故障，而是因为它正在安静地运行。

**成功时你会看到：** 终端停在当前画面，没有回到可以继续输入命令的状态。即使没有提示，也可以继续下一步。

---

## 第 4 步：打开 SpotBrief 安装页面

1. 回到 Google Chrome。
2. 点击最上方的网址输入框。
3. 输入下面的网址：

```text
http://127.0.0.1:4173/dist/
```

4. 按回车键。

**成功时你会看到：** 页面左上角显示 `SpotBrief`，页面中有一个橙色的 SpotBrief 按钮，并显示“书签已准备好”。

如果显示“无法访问此网站”，请直接查看本文最后的“常见问题 1”。

---

## 第 5 步：显示 Chrome 书签栏

书签栏就是 Chrome 地址栏下面的一条横栏，可以放常用网页和 SpotBrief 按钮。

1. 同时按下：

```text
Command + Shift + B
```

2. 看看 Chrome 地址栏下方是否多出了一条横栏。

如果按一次没有出现，再按一次。

**成功时你会看到：** 地址栏下面出现一条可以放书签的区域。里面可能已有其他网站，也可能是空白的。

---

## 第 6 步：把 SpotBrief 安装到书签栏

1. 在安装页面中找到橙色的 `SpotBrief` 按钮。
2. 把鼠标放在这个按钮上。
3. 按住鼠标左键，先不要松开。
4. 一直拖到 Chrome 地址栏下面的书签栏。
5. 到达书签栏后，松开鼠标左键。

这里的操作叫“拖动”，不是普通点击。

**成功时你会看到：** Chrome 书签栏中多出一个名为 `SpotBrief` 的书签。

如果你只是点击了橙色按钮但没有拖动，它不会完成安装。请重新按住按钮并拖到书签栏。

---

## 第 7 步：在网页上选择需要修改的位置

这一部分是 SpotBrief 最重要的操作。建议第一次先在 SpotBrief 安装页面上练习。

### 7.1 启动选择工具

1. 保持当前网页打开。
2. 点击 Chrome 书签栏里的 `SpotBrief`。

**成功时你会看到：**

- 网页右侧出现一个浅米色的 SpotBrief 工作面板。
- 面板顶部显示正在检查网页的状态。
- 鼠标移动到网页内容上时，会出现一圈轮廓。

如果点击书签后完全没有变化，请看“常见问题 3”。

### 7.2 先用鼠标移动查看位置

先不要点击，只移动鼠标。

当鼠标经过标题、按钮、图片或某一块内容时，SpotBrief 会用轮廓标出它认为你正在指向的位置。

悬停只是在“预览位置”，不会把它加入任务书。

选择前请观察轮廓：

- 如果你想修改一个按钮，轮廓最好只包住按钮。
- 如果你想修改一整块内容，轮廓应该包住整块区域。
- 如果轮廓包住了整个网页，通常说明你选得太大。

### 7.3 单击选择一个位置

当轮廓正好包住你想修改的位置时：

1. 点击鼠标左键一次。
2. 原网页的按钮或链接不会被真正触发。
3. 右侧面板会出现一张“目标卡片”。

**成功时你会看到：**

- 被选中的位置保持选中轮廓。
- 右侧出现“目标 1”卡片。
- 卡片里显示元素名称、标签和定位信息。
- 卡片下方有一个可以填写单独说明的输入框。

SpotBrief 默认是“单选”：如果你没有按 Shift，又点击了另一个位置，原来的选择会被新位置替换。

### 7.4 同时选择多个位置

例如，你想同时修改“删除按钮”和“取消按钮”：

1. 先正常点击第一个按钮。
2. 按住键盘上的 `Shift` 键。
3. 在按住 Shift 的同时，点击第二个按钮。
4. 松开 Shift。

如果还要增加第三个位置，继续按住 Shift 点击第三个位置。

**成功时你会看到：** 右侧依次出现“目标 1”“目标 2”等多张卡片，网页上也有多个选中轮廓。

### 7.5 取消某一个位置

有两种简单方法：

方法一：在右侧目标卡片中，点击右上角的 `×`。

方法二：按住 `Shift`，再次点击已经选中的网页位置。

**成功时你会看到：** 对应的目标卡片和选中轮廓消失，其他目标仍然保留。

### 7.6 如果选错了，撤销上一次操作

你可以点击右侧面板底部的“撤销”，也可以同时按下：

```text
Command + Z
```

这样会恢复到上一次选择状态。

提醒：当你正在输入文字时，`Command + Z` 可能会撤销输入框里的文字。建议先点击网页空白位置，再使用这个快捷键撤销选择。

### 7.7 清空全部选择

如果想重新开始：

- 点击面板底部的“清空选择”；或者
- 按一下键盘上的 `Esc`。

**成功时你会看到：** 所有目标卡片和选中轮廓都消失，但右侧 SpotBrief 面板仍然存在。

### 7.8 暂停和恢复选择

当没有选中任何位置时，按 `Esc` 可以暂停检查；再次按 `Esc` 可以恢复。

也可以点击面板顶部的暂停按钮。

暂停后，你可以正常点击和操作原网页，不会一直选中元素。

### 7.9 怎样判断自己选得对不对

正确选择的简单标准：

- 轮廓刚好包住你要修改的东西。
- 右侧卡片中的名称与你看到的内容相符。
- 如果只想改按钮，就不要选择整个页面。
- 如果想让三张卡片一起调整布局，可以选择包住三张卡片的外层区域。

错误示例：

> 我只想把“删除”按钮变红，却选中了整个网页。

正确做法：

> 把鼠标移动到“删除”按钮文字或按钮边缘，确认轮廓只包住按钮，再点击。

当前版本暂时不能使用方向键切换父元素、子元素或相邻元素。请以鼠标轮廓为准进行选择。

## 第 8 步：填写修改要求

选择完成后，在右侧面板填写任务。你不需要每个输入框都填，但“全局修改目标”最重要。

### 8.1 为某一个位置填写单独说明

每张目标卡片下面都有一个输入框，提示文字类似“这个元素需要如何修改？”。

这个输入框只说明当前这一张卡片里的元素。

例如，你选中了删除按钮，可以填写：

```text
把这个按钮改成红色描边。鼠标放上去时显示浅红色背景。
```

如果你同时选择了两个位置，可以分别写：

目标 1：

```text
把这个标题字号调大，并与左边对齐。
```

目标 2：

```text
把这个按钮放到标题右边。
```

不要只写：

```text
改好看一点。
```

因为“好看”没有明确标准。尽量说出颜色、位置、大小、显示时机或点击后的变化。

### 8.2 填写“全局修改目标”

这是整份任务最重要的输入框，用来说明你最终想达到什么效果。

推荐按照下面的顺序写：

1. 现在有什么问题。
2. 希望改成什么样。
3. 哪些地方不要改变。

完整示例：

```text
当前删除按钮与普通按钮看起来一样，用户不容易意识到这是危险操作。

请把删除按钮改成红色描边样式。默认状态不要太醒目，鼠标悬停时显示浅红色背景。

点击后增加二次确认，不要改变其他按钮的样式。
```

再举一个布局修改的例子：

```text
当前页面在大屏幕上内容都挤在中间，两边空白太多。

请适当扩大主要内容区域，让标题、图片和卡片充分利用电脑屏幕，同时保持文字容易阅读。

只调整电脑网页，不需要处理手机和平板。
```

### 8.3 填写“相关代码”

这个区域不是必填。

“相关代码”默认是收起的。点击“相关代码”这一行即可展开，再次点击即可收起。收起不会删除已经粘贴的代码。

如果你不知道什么是代码，或者手上没有代码，**直接留空即可**。SpotBrief 仍然可以生成任务书。

如果开发人员或 AI 已经给了你一段代码，可以把它复制进来：

1. 复制相关代码。
2. 点击“相关代码”下面的大输入框。
3. 按 `Command + V` 粘贴。

输入框旁边会显示字符数量，帮助你判断内容是否过长。

### 8.4 选择代码语言

相关代码上方有一个语言选择框，例如：

- TSX
- JSX
- TypeScript
- JavaScript
- Vue
- HTML
- CSS
- SCSS
- Other

如果你不知道应该选哪一个：

- 看到大量 `<div>`、`<button>`，可以选 HTML。
- 内容主要是颜色、字号、宽度，常出现 `{ }`，可以选 CSS。
- 完全无法判断，就选 Other。
- 没有粘贴代码时，这个选项不用管。

选择错误通常不会导致任务书无法生成，它主要是帮助 AI 更容易阅读代码。

### 8.5 选择“修改约束”

修改约束用来告诉 AI“哪些事情不要做”。点击方框即可勾选。

“修改约束”默认是收起的，标题右侧会显示已经选择了几项。点击标题即可展开。

常见选项的简单解释：

- **不修改共享组件**：不要因为改当前按钮，影响其他页面的同类按钮。
- **不要安装新依赖**：不要额外下载新的代码工具包。
- **不修改无关文件**：只动与当前任务有关的文件。
- **保持响应式兼容**：不要让不同屏幕下的网页布局坏掉。
- **保持现有交互**：没有明确要求时，不改变按钮点击等原有行为。
- **保持可访问性**：尽量保证键盘操作、标签和阅读辅助功能正常。
- **先展示修改方案**：让 AI 先说明准备怎么改，再真正修改。
- **修改后运行检查**：修改完成后，让 AI 执行合适的检查或测试。

SpotBrief 已经默认勾选下面五项：

- 不要安装新依赖
- 不修改无关文件
- 保持响应式兼容
- 保持可访问性
- 修改后运行检查

你可以按照任务需要取消或增加选项。

如果一个都不选，SpotBrief 也会在任务书中加入一组安全的默认要求。

### 8.6 填写完成后检查一遍

生成前请快速确认：

- 是否至少选中了一个真正要修改的位置。
- “全局修改目标”是否说清了想改什么。
- 每个目标的单独说明是否对应正确元素。
- 有没有把密码、密钥、个人资料或公司机密粘贴进去。
- 修改约束有没有互相冲突。

生成预览后点击“返回修改”，全局目标、相关代码、语言、约束和截图说明都会保留。

## 第 9 步：生成任务书

1. 找到面板底部的橙色“生成任务书”按钮。
2. 点击一次。

也可以使用快捷键：

```text
Command + Enter
```

**成功时你会看到：** 面板内容变成一份以 `Frontend Change Brief` 开头的完整文字任务书。

任务书通常包括：

- 修改目标
- 当前页面地址和屏幕大小
- 你选择的网页位置
- 每个位置的单独说明
- 截图文件名和截图说明（如果添加了截图）
- 相关代码
- 修改约束
- 给 AI 的执行要求

---

## 第 10 步：复制任务书并交给 AI

### 10.1 复制普通任务书

1. 点击面板底部的“复制任务书”。
2. 打开 Codex、Cursor 或 Claude Code。
3. 点击聊天输入框。
4. 按 `Command + V` 粘贴。
5. 检查内容是否完整。
6. 再发送给 AI。

当前版本复制后可能没有明显的成功动画。最简单的确认方法，是在 AI 输入框中粘贴一次，看看是否出现以 `# Frontend Change Brief` 开头的文字。

### 10.2 下载为文件

点击“下载 MD”，Chrome 会下载一个 `.md` 文件。

`.md` 是一种文字文档，可以交给 AI，也可以用普通文本工具打开。

### 10.3 复制 JSON

“复制 JSON”主要给开发人员或其他工具使用。普通用户不需要使用它，优先点击“复制任务书”即可。

---

## 第 11 步：截图和移动面板

如果文字很难说明问题，可以点击“截取页面区域”：

1. 点击按钮后，Chrome 会询问你要分享哪个画面。
2. 选择正在使用 SpotBrief 的当前标签页，再点击“分享”。
3. 面板暂时隐藏后，按住鼠标左键，从截图区域一个角拖到另一个角，再松开。
4. 面板恢复并显示图片预览。你可以复制 PNG、下载 PNG、重新截图或删除。
5. 在图片下方的“截图说明”中写清楚图片里需要关注或修改的位置。

截图只留在当前网页内存中，不会自动上传。按 `Esc`、取消分享或选择太小都只会取消本次截图，不会清空已经填写的内容。它只能截当前屏幕能看到的区域，不是整页长截图。

如果面板挡住内容，在电脑网页上按住顶栏没有按钮的空白位置拖动即可。SpotBrief 会记住位置；点击顶栏的 `⌂` 可回到默认右上角。

---

## 第 12 步：暂停、最小化或关闭 SpotBrief

面板顶部有几个小按钮：

- `Ⅱ`：暂停选择，让网页恢复正常点击。
- `⌂`：把面板恢复到默认位置。
- `—`：折叠面板，减少遮挡。
- `×`：完全关闭 SpotBrief。

完成任务后建议点击 `×` 关闭。

**成功时你会看到：** 右侧面板和网页上的所有选择轮廓消失，网页可以正常操作。

如果之后还想继续使用，重新点击书签栏里的 SpotBrief 即可。

---

## 第 13 步：使用结束后关闭本地页面服务

只有在你确定暂时不用 SpotBrief 安装页面时，才需要做这一步。

1. 回到之前一直开着的终端窗口。
2. 同时按下 `Control + C`。
3. 关闭终端窗口。

注意这里是 `Control + C`，不是 `Command + C`。

关闭后，已经拖进 Chrome 书签栏的 SpotBrief 仍然可以继续使用，因为完整工具代码已经保存在书签中。

## 常见问题

### 常见问题 1：安装页面显示“无法访问此网站”

最常见的原因是第 3 步的本地页面服务没有启动。

请检查：

1. 终端窗口是否还开着。
2. 启动命令是否整行复制。
3. 输入命令后是否按了回车。
4. 终端里是否出现红色错误文字。

如果终端显示端口已经被使用，可能代表服务已经在运行。先直接重新打开：

```text
http://127.0.0.1:4173/dist/
```

### 常见问题 2：页面一直显示“正在准备书签”

1. 等待几秒钟。
2. 按 `Command + Shift + R` 强制刷新页面。
3. 确认网址末尾是 `/dist/`。
4. 仍然失败时，关闭终端服务并按照第 3 步重新启动。

不要把还没有准备好的灰色按钮拖进书签栏。

### 常见问题 3：点击书签后没有反应

先确认当前网页是不是下面这些页面：

- `chrome://` 开头的 Chrome 设置页面
- Chrome 新标签页
- Chrome 网上应用店
- 浏览器自己的内部页面

这些页面禁止书签脚本运行，不是 SpotBrief 损坏。

请打开一个普通网站，或者打开 `http://127.0.0.1` 开头的本地网页，再点击 SpotBrief。

如果安装时只是收藏了安装页面，而不是拖动橙色 SpotBrief 按钮，也会没有效果。请删除错误书签，再重新执行第 6 步。

### 常见问题 4：我选中了整个网页

1. 点击“清空选择”。
2. 把鼠标慢慢移动到真正想修改的按钮、标题或图片上。
3. 确认轮廓缩小到正确范围。
4. 再点击。

### 常见问题 5：点击后网页按钮没有执行

这是正常的。检查模式会暂时拦截网页点击，防止你在选择链接或删除按钮时误操作。

想正常操作网页时，可以暂停或关闭 SpotBrief。

### 常见问题 6：复制后不知道是否成功

打开一个空白文本框或 AI 聊天输入框，按 `Command + V`。

如果出现 `Frontend Change Brief`，说明复制成功。

如果没有内容，可以点击“下载 MD”，然后把下载的文件交给 AI。

### 常见问题 7：右侧面板挡住了网页

点击面板顶部的 `—` 折叠面板。需要继续填写时，再次点击书签栏中的 SpotBrief。

### 常见问题 8：选中的内容后来消失了

网页内容可能会自动刷新或变化。被选择的元素如果被网页删除，目标可能失效。请删除失效目标，再重新选择新出现的内容。

---

## 哪些页面不能使用

SpotBrief 不能在 Chrome 自己的内部页面运行，例如：

- Chrome 设置页面
- Chrome 新标签页
- Chrome 网上应用店
- `chrome://` 开头的页面

部分网页中的嵌入区域也会受到浏览器安全限制。特别是来自其他网站的嵌入页面，SpotBrief 通常只能选中外面的整体区域，不能读取里面的内容。

---

## 隐私提醒

SpotBrief 的处理在浏览器本地完成，不会主动把网页内容上传到服务器，也不会读取 Cookie 或本地项目源码。

但是，当你把生成的任务书粘贴给 AI 时，任务书中的文字会发送给你使用的 AI 服务。因此请在发送前检查：

- 不要包含密码。
- 不要包含 API Key 或密钥。
- 不要包含身份证号、手机号等个人信息。
- 不要粘贴公司机密代码。
- 如果页面含有敏感内容，先阅读任务书预览并删除不该发送的内容。

## 最短操作口诀

只记住下面七句话，也可以完成一次使用：

1. 保持终端里的本地服务运行。
2. 打开普通网页。
3. 点击书签栏里的 SpotBrief。
4. 鼠标移动确认轮廓，再点击要修改的位置。
5. 填写全局修改目标。
6. 点击“生成任务书”。
7. 点击“复制任务书”，粘贴给 AI。
